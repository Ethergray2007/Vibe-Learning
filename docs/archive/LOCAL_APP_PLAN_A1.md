## 课程与界面

固定课程 tinyrenderer/level-01。从审核模板重建完整源文件，仅开放 EDIT BEGIN/END 间编辑；原课程文件只读。单次编译仅包括本次源文件及 upstream/tgaimage.cpp，固定 upstream、support 包含目录。编译器用绝对路径、独立参数启动，不拼接 shell 命令。子进程 PATH 包含工具链目录。

展示 16×16 BMP，放大到 320×320，最近邻显示；不增加图片转换依赖。必须实际验证浏览器解码，失败显示预览错误。

按现有二级标题解析 lesson.md：基本题面默认显示；典型错误主动展开；答案解析及 reference.cpp 只在点击查看答案后返回并记录已看答案。A1 暂不开放逐级提示及迁移练习，后续 A2 实现。不要把全文传给页面后仅用 CSS 隐藏；标题缺失、重复或未知时明确报错，不回退全文。支持必要 Markdown 子集，转义原始 HTML，链接只允许明确支持的安全类型。

## 运行与输出

一次只有一个活动运行，不排队；忙时返回明确冲突结果。运行前保存成功；使用不可变代码快照。允许运行中继续编辑，但标明结果对应旧快照。

编译超时 30 秒，执行超时 3 秒；日志有长度上限，达到上限后继续消费或主动终止，不因管道阻塞而挂起。子进程树超时终止并确认退出；终止失败记 system_error，阻止新运行并提示重启和检查遗留进程。使用 taskkill 的 PID 只能来自本服务实际启动的进程。

本次进程成功退出后检查 BMP/TGA 存在、结构有效且为 16×16；失败记 output_error。A1 不判断红点任务完成，不创建通关状态。

运行开始清空旧预览；仅当前 runId 的成功结果能更新图片。URL 带 runId，响应禁止缓存，迟到响应不能覆盖当前结果。图片仅通过专用路由提供，不暴露文件系统静态目录。

## 保存与生命周期

用户数据根：%LOCALAPPDATA%\VibeLearning\。
- drafts/tinyrenderer/level-01/starter.cpp：完整草稿。
- drafts/tinyrenderer/level-01/learning.json：已看答案等必要标记。
- runs/<sessionId>/<runId>/：本次 starter.cpp、run.exe、preview.bmp、framebuffer.tga。

防抖自动保存加手动保存；显示未保存、保存中、已保存、失败。客户端保存按顺序处理或使用修订号，旧保存响应不能覆盖新状态，运行快照必须对应本次确认保存的代码。同目录临时文件后替换；失败保留上次有效草稿。恢复时检查模板固定部分，不静默丢弃不兼容草稿。

首版采用单实例保护，避免多个服务同时写草稿或清理活动目录；重复启动提示已有实例，或安全复用原实例。锁必须处理正常退出和遗留状态，不能仅凭一个 PID 就断定进程身份或杀进程。

正常退出清理所属活动进程。关闭浏览器不会自动结束服务；关闭服务窗口后能否完整终止进程树必须测试。强制结束服务时不能保证清理，下一次启动应识别异常状态，不能宣称已清除所有孤儿进程。

清理仅针对已确认不活跃、由本应用创建的运行目录，永不删除 drafts。递归删除前验证绝对路径位于预期根内；拒绝通过链接或目录联接越界。无法确认目录或进程归属时保留并提示，不盲目清理或杀进程。

## 本机访问边界

校验精确 Host（含端口）、请求来源和会话令牌，不开启 CORS；状态变更使用非 GET 请求。令牌随机且每次服务启动更换，不写入诊断日志。不得假设所有合法 GET 都带 Origin，具体鉴权和浏览器会话引导可在应用模块内部设计并测试。限制请求体、日志及输出读取大小，拒绝路径越界。

这些措施不构成 C++ 沙箱：用户代码仍以当前用户权限运行，仅用于审核过的内部课程。不承诺可运行任意恶意代码。
