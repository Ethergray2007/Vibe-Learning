版本：v0.5
日期：2026-10-16
状态：当前产品范围；已根据真人试用反馈实现第一关题面、完整代码、AC 判题与章节路线。独立 R1 与学习效果验证待完成。

## 1. 问题与目标用户

帮助能写简单代码、但难以理解真实项目的学习者，通过阅读少量代码、动手修改、运行观察和测试反馈建立理解。用户可能主要依靠 AI Coding Agent 编程，需要课程解释为什么修改，而不只是展示答案。

首门课暂按官方仓库 https://github.com/ssloy/tinyrenderer 制作，使用 C++。课程专项须核对仓库身份、记录具体 commit、来源和必要署名，不得把当前目录中的源码文件直接当成已经验证的版本。

当前优先验证学习效果，而非自动制课效率。先由项目发起者试学，再邀请 3～5 人。建议验证指标：至少 3 人无需现场讲解完成前两关，并能完成相似但未见过的小任务、解释修改原因。指标属于试用建议，不是已取得的结果。

## 2. 产品形式与成本

首版面向 Windows：本地程序启动，在浏览器显示界面，本地编译运行 C++，课程、代码和进度保存在本机。无需租用云服务器，学习阶段无需调用 AI。仍有本机资源、首次环境配置、维护及后续分发成本。

首版使用现有 MSYS2 UCRT64 g++，启动时检查实际可用性；缺失时提供指引，不自动安装。工具链随安装包分发仍暂缓。首次配置完成且课程资源齐备后，核心学习流程应离线可用。独立桌面窗口和包含工具链的安装包暂缓。

最新用户决定：保留 Node.js 本地服务，前端改用 React + Vite + Tailwind CSS + shadcn/ui（Radix），构建后本地离线运行。应用源码范围为 apps/local/**，详细方案与验收见 [本地应用实施决定](LOCAL_APP_PLAN.md)。

## 3. 核心流程

首次打开 → 检查编译环境 → 查看课程目标及前置知识 → 进入关卡 → 阅读讲解与源码 → 修改代码 → 编译运行 → 查看本次图片或错误 → 检查本关 → 查看提示或解析 → 继续下一关。

关闭后重新打开，恢复最后保存的代码及学习进度。运行成功与学习通关分开：编译成功不代表完成任务；点击提交评测，像素条件全部满足后显示绿色 AC 并保存通过状态。

课程制作使用现有 AI Coding Agent 辅助，由作者试做审核。本轮不开发网站内 AI 制课。

## 4. 交付顺序

### 第一阶段：单关可运行闭环

唯一整体验收路径：启动应用 → 打开第一关 → 修改 C++ 像素颜色 → 点击运行 → 看见新图片 → 关闭重开后恢复已保存代码。

先制作第一关完整样例和最小课程格式，再实现应用。运行结果必须区分成功、编译失败、运行失败和超时，并明确本次图片所属运行。具体字段由课程格式文档确认。

### 第二阶段：前两关学习验证

增加基础线段关卡、明确检查规则、提示解析、进度和简单解锁，完成一次真实试学。收集卡点、尝试次数和迁移练习结果，先改课程，再决定扩展功能。

### 后续候选单元

修复不同方向线段 → 三角形轮廓 → 三角形填充 → 独立图案挑战。该顺序是候选教学设计，不是当前开发任务。完整三维渲染、相机、光照和纹理后置。

## 5. MVP 功能与验收

| 功能 | 阶段 | 验收标准 |
| --- | --- | --- |
| 本地启动与环境检测 | 第一阶段 | 有明确启动入口；可编译最小样例；缺失环境时指出缺失项及处理方法 |
| 课程阅读 | 第一阶段 | 第一关目标、前置知识、操作范围和完成条件完整；资源齐备后离线可读 |
| 编辑与保存 | 第一阶段 | 保存状态明确；重开恢复最后保存内容；保存失败可见；重置前确认 |
| 编译运行 | 第一阶段 | 完整 main.cpp 可编辑；正确代码可运行；错误信息可读；死循环有超时终止；失败后可再次运行 |
| 图像预览 | 第一阶段 | 成功后显示本次图片；失败不冒用旧图；原格式不能显示时做最小转换 |
| 关卡检查 | 第一关已接入 | 参考实现及不同正确实现通过；典型错误不能通过；不只依赖整图逐字节一致 |
| 提示与解析 | 第二阶段 | 有逐级提示；通过后开放完整解析；解释代码行为而非只给答案 |
| 进度与解锁 | 第二阶段 | 通过才解锁下一关；重开保留进度；重做失败不撤销已通过状态 |
| 学习记录导出 | 第二阶段 | 用户手动导出完成情况、尝试次数和反馈，不自动上传 |

本地资料可被用户查看，首版用于自学，不提供考试防作弊保证。图片正确也不能单独证明理解，需结合迁移练习和解释。

## 6. 页面清单

- 课程路线：展示四个章节的目标、练习与开放状态。第一关可学习，第二关草稿，三角形及三维、光照方向仍在规划。
- 关卡学习页：讲解、代码编辑、保存、运行、图片、错误、检查和提示解析。
- 环境检查区域：首次使用或环境异常时展示，可作为首页内区域，不强制独立页面。

不做登录页、云端管理后台、个人中心或独立证书页。

## 7. 本地执行边界

仅接受本机连接；首版只运行经过审核的内置课程。学习代码使用专用工作目录，限定预期文件操作范围，编译及运行应有终止机制。保存内容不得意外覆盖原课程或其他用户文件。

工作目录和超时不是完整安全沙箱，不宣称可安全运行任意恶意 C++。不开放陌生课程包脚本或插件执行。更强隔离、资源限制及分发前的安全要求由应用方案明确实际能力和限制。

## 8. 暂不开发

云服务器、云数据库、登录与多账号、跨设备同步、云判题队列、在线 AI 助教、自动仓库制课、课程市场、插件/MOD/SDK、多语言、自由安装依赖的终端、复杂版本迁移、macOS/Linux 同步适配、完整安装程序及完整三维课程。

不照搬旧规划里的课程包导入导出、审核发布平台和插件协议；首版课程随应用提供，保留必要的本地内容格式即可。

## 9. 协作与决策

主对话维护范围及验收；课程专项负责课程；应用专项负责本地工具；Review 专项针对固定版本只读审查。任务与依赖见 [TASKS.md](TASKS.md)，通用规则见 [AGENTS.md](AGENTS.md)，课程约定见 [COURSE_FORMAT.md](COURSE_FORMAT.md)。

课程专项已记录官方仓库及 commit 706b2dfecff65daeb93de568ee2c2bd87f277860；主对话已接受普通文件课程组织，详见 COURSE_FORMAT.md。来源及测试为交付记录，本轮未独立复测。运行字段、工具链、应用方案和目录边界已在 P2 确认；首次安装体验与实际运行效果待 A1 验证。Windows 与浏览器本地界面是当前推荐基线，未代表已完成技术验证。




## 10. 2026-10-16 真人试用后的调整

用户指出题面冗杂、只允许局部编辑、正确答案缺少 AC；并要求使用 shadcn/ui 和显示后续章节。本轮据此调整第一关，不扩大到第二关执行。默认题面按题目描述、输入、输出、样例组织；知识与题解分标签。完整代码可编辑，运行与提交分开，服务端像素判题、绿色 AC 反馈和本地持久化进度。路线显示计划内容但不虚构已开放关卡。原 A1 不判题、局部编辑、无前端依赖的约束不再适用。
