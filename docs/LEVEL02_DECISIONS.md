# 第二关接入决定

日期：2026-10-16。依据课程交接 APP_INTEGRATION_LEVEL02.md；方案已确认，应用尚未接入。完整产品需求以 docs/product/PROJECT_PLAN.md v0.6 为准。

## 已确认

1. 保留既有精确像素规则：n=max(|dx|,|dy|)，采样 i=0..n，非负坐标半格向较大的整数取整；n=0 只画端点。接受产生相同像素集合的不同实现，不要求照抄 DDA。不同 Bresenham 取整可以合理但不符合本题契约，反馈须说明本题规则，不能称算法普遍错误。
2. 学习者可编辑完整文件。运行编译普通 main；提交单独编译学习者翻译单元，用构建参数定义 COURSE_TEST 并把 main 重命名为宿主保留名称，再与独立检查器及固定图像代码链接。不改写原源文件、不按字符串截取函数、不向检查器翻译单元传播学习者宏。
3. 全局可链接接口保持 void line(int ax,int ay,int bx,int by,TGAImage &image,TGAColor color)。普通无条件 main、删除 EDIT 注释、辅助函数和不同变量名都应兼容；接口缺失或签名错误为 CE。
4. 运行展示 main 产生的图片；提交调用 line 检查行为，不要求 main 保存默认图片。提交成功可以 image=null，前端不得依赖图片才显示 AC。
5. 复用端点穷举逻辑，补充独立正确实现、黑色/多颜色、多色背景、连续交叉绘制和硬编码样例的错误变体。检查器正常不匹配为 WA，异常非零 RE，死循环 TLE，平台材料与持久化错误 SE。
6. 宿主确认全部必需检查完成才 AC，不能只凭退出 0 或学习者输出 PASS。测试资料及完成报告由宿主掌握；当前本地执行仍不具备完整防作弊沙箱能力。

- 第一关通过后解锁第二关；后续失败不撤销历史 AC。未解锁的运行/提交请求在宿主拒绝，不能仅禁用按钮。
