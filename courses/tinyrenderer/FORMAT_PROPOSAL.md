# 最小课程格式建议（提案，未确认）

状态：仅供主对话审阅；不是应用接口、导入协议或插件契约。2026-10-16。

先用普通文件验证教学，不引入课程包、数据库或运行时协议。

| 资料 | 内容 |
| --- | --- |
| SOURCE.md | 官方来源、固定提交、改编说明和许可核对状态 |
| level-01/lesson.md | 学习目标、必要解释、任务、样例、规则、图像、提示、迁移练习 |
| level-01/starter.cpp | 可以编译运行、但尚未完成任务的初始代码 |
| level-01/reference.cpp | 主任务参考实现 |
| level-01/transfer.cpp | 迁移练习参考实现，学习时延后展示 |
| level-02/… | 相同组织方式 |
| support/ | 固定的图像输出辅助代码，学习者不用编辑 |
| upstream/ | 固定版本的官方源码快照 |
| checks/ | 课程作者使用的验证程序；不是应用执行接口 |
| artifacts/ | 验证输出图片与日志 |

每关文字至少明确：编号、前置关卡、目标、允许编辑位置、输入范围、输出约定、完成标准、公开例子、提示、解析、迁移检查。暂不转成 JSON Schema。

主任务通过只表示“完成操作”；独立完成迁移题并解释预测，才记录“理解得到验证”。可请 AI 解释编译错误、给提示；首次迁移尝试先独立预测，再运行，不能把复制参考答案当作理解证据。

主对话待决定：是否接受此文件组织；如何记录迁移解释；何时显示答案。未确认前，应用专项不得据此固化接口。
