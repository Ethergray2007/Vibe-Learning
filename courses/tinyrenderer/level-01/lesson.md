# 第一关：改一个像素，看到变化

建议 10～15 分钟。前置：会改数字、保存文件；无需图形学基础。

## 目标
能指出颜色和位置分别在哪里修改，预测一次修改的图像结果，并完成“打开题目 → 改颜色 → 本地编译运行 → 看见新图片”。

## 只学本题需要的 C++
`TGAImage image(16, 16, TGAImage::RGB);` 创建宽高各 16 像素的黑色图片。变量 `image` 是这张图片的名字。
`const TGAColor color = {255, 255, 255, 255};` 给颜色起名。`const` 表示程序运行时不再改变这个变量，但你可以改源文件再编译。
此版本大括号中的四个数字依次是 **蓝、绿、红、透明度（BGRA）**，不是 RGB；前三项范围 0～255，最后一项保持 255。本题图片是 RGB，透明度不参与比较。
`image.set(4, 6, color);` 把位置 `(4,6)` 的一个像素设为该颜色。左上角是 `(0,0)`，x 向右、y 向下，因此它是第 5 列第 7 行。坐标范围 0～15。
每条语句以分号结尾。`#include` 引入已有工具；`main` 是程序入口；保存工具及返回值无需修改。

## 任务与可修改范围
打开 `starter.cpp`。先运行一次，看见黑底白点，再仅修改 `EDIT BEGIN/END` 之间颜色的前三个数字，使 `(4,6)` 变成纯红色（RGB 为 255,0,0）。不要改坐标、图片大小、保存函数或官方源码。
没有键盘输入。成功运行产生 `preview.bmp` 和 `framebuffer.tga`。本地操作命令见根目录 README；应用中的编辑与运行按钮由应用专项实现，本次只交付课程材料。

## 公开样例和完成条件
| 情况 | 预期 RGB | 预期位置 |
| --- | --- | --- |
| 初始代码 | 白色 (255,255,255) | (4,6) |
| 完成主任务 | 红色 (255,0,0) | (4,6) |
| 其他 255 个像素 | 黑色 (0,0,0) | 除目标点以外 |

检查：编译成功、进程返回 0、两个输出均为 16×16，逐像素比对且方向一致。仅文件存在或“有红色”不算完成。初始代码应不通过主任务检查。
预期图像：16×16 黑底，左上区域一个红点。以最近邻放大到 320×320，红点显示为 20×20 方块；原图依然只有一个像素改变。应用应允许在初始图和本次图之间比较，不能平滑插值模糊像素。

## 典型错误
| 错误 | 看见什么 | 怎样修正 |
| --- | --- | --- |
| 写成 `{255,0,0,255}` | 蓝点 | 本版本首项是蓝，不是红 |
| 改成 `set(6,4,...)` | 点移到错误位置 | 先 x 后 y |
| 将坐标设为 16 | 全黑；set 忽略越界 | 最后一个合法坐标是 15 |
| 漏掉分号 | 编译失败 | 查看报错行及前一行 |
| 没保存或运行旧程序 | 仍是白点 | 保存、重新编译成功，再运行；失败时不要展示旧图为新结果 |

## 逐级提示
1. 位置保持不变，只检查颜色定义。
2. 纯红色需要红通道最大、蓝和绿为零。
3. BGRA 顺序下填写 `{0, 0, 255, 255}`。

## 答案解析
完整代码见 `reference.cpp`。只改变颜色参数，`set` 的坐标没有改变，所以图片中仍然只有原来的一个点；只让红通道非零，点就从白变红。
