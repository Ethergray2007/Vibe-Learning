# 第二关：把散点连成线

建议 25～35 分钟。前置：完成第一关，知道坐标、颜色和保存运行；只需整数加减，不要求掌握 Bresenham 算法。

## 目标
用循环从起点走到终点，解释为什么线段不能只画两个点。

方法与范围：这里采用便于理解的等步数插值（DDA），是对官方线段教程的教学改编，不声称是上游的整数 Bresenham 实现；不做速度优化、模型读取或三维任务。

## 只学本题需要的 C++
`int` 保存整数，`double` 保存小数。`bx-ax` 是横向位移，可为负数。`std::abs` 取绝对值，`std::max` 选较大值。
`TGAImage &image` 中的 `&` 让函数修改调用者的图片；不用学习指针或内存管理。
`if (...) { ... }` 在条件成立时执行，`return;` 结束当前函数。
`for (int i=0; i<=steps; ++i)` 让 i 从 0 每次加 1，直到 steps，包含两端。
用 `steps=max(abs(bx-ax),abs(by-ay))` 表示走几步，较长方向每步恰好走一格。
`double(i)/steps` 得到进度 t；例如 1/4 应为 0.25，若两个操作数都是整数会得到 0。
当前位置为 `ax+(bx-ax)*t`、`ay+(by-ay)*t`。`std::round` 四舍五入到像素格，再用 `int(...)` 转成整数；本题所有坐标非负，恰好 .5 时向较大的整数取整。
当起终点相同时 steps 为 0，直接画一个点并返回，不能除以零。

## 任务与可修改范围
在 `starter.cpp` 中只修改 `line` 函数的 EDIT 区域。函数名、参数、main、辅助代码保持不变；可以用多种写法，只按行为检查。
输入契约：16×16 图片，端点坐标都是 0～15 的整数，颜色由调用者提供。支持任意斜率、负方向、反向端点、水平、竖直、单点。越界端点不在本关输入范围；不要求实现裁剪。
输出契约：按上面的等步数插值和取整规则设置像素，包含两个端点，不修改线段之外的像素，不能写死图片颜色。不同取整规则的合法图形算法可能画出另一组像素，本题要求的是上述明确规则。

**预期图像**：默认图是黑底上从左上向右下延伸的 9 个绿色格子，形成阶梯线。初始代码只有两个绿色端点，应不通过检查。图片最近邻放大显示，不应期待抗锯齿光滑曲线。

## 典型错误
| 错误片段/行为 | 失败原因 | 能揭示它的例子 |
| --- | --- | --- |
| `i < steps` | 漏终点 | 水平线 |
| `double t = i / steps` | 先整数除法，小数已丢失 | 默认斜线 |
| 只按 x 增加循环 | 竖线、反向线失效 | 竖线和反向对角线 |
| steps 只用 abs(dx) | 陡线中间有缺口 | (2,1)→(3,4) |
| 未处理 steps=0 | 除零后坐标无效 | 单点 |
| 写死绿色 | 不遵守调用者参数 | 黄色迁移题 |
| 每次先清空图片 | 擦掉已有内容 | 背景保持检查 |

## 逐级提示
1. 先求横向和纵向分别相差多少，选距离更大的方向决定步数。
2. 单点单独处理；其他情况让 i 从 0 走到 steps，算 t 再算坐标。
3. 循环内需要 `double(i)/steps`、两次 `std::round` 和一次 `image.set(x,y,color)`。

## 答案解析
见 `reference.cpp`。长方向每步只走一格，短方向按相同比例变化，所以陡线也连续；带符号的 dx、dy 自然处理倒着画。包含 i=0 与 i=steps 保证两个端点都出现。传入的 color 原样交给 set，使函数可重复使用。

## 迁移练习：倒着画一条陡线
保留自己的 line 函数，只修改 main 中的调用，画从 `(5,12)` 到 `(2,3)` 的黄色线（RGB 255,255,0）。不要逐点写死答案。
先独立填写：dx、dy、steps 是多少？i=0、3、6、9 分别落在哪？再运行，交换端点重画，比较两张图片是否相同。
完成条件：10 个黄色点、两端正确、交换端点图像一致；解释为什么 steps 不能取 3，为什么 i 要包含 9。人工核对预测与解释，程序结果不能单独证明理解。
答案：dx=-3，dy=-9，steps=9；四个指定点依次为 (5,12)、(4,9)、(3,6)、(2,3)。全部像素为 (5,12),(5,11),(4,10),(4,9),(4,8),(3,7),(3,6),(3,5),(2,4),(2,3)。黄色 BGRA 为 `{0,255,255,255}`。参考调用见 `transfer.cpp`，它复用参考函数；学习者应复用自己的函数。
